# Security Policy

Tricord is under active development. Do not assume an unreleased version is suitable for production deployment.

## Reporting vulnerabilities

Please **do not** disclose vulnerabilities in public issues, discussions, or pull requests.

Use GitHub's private vulnerability reporting on the [Tricord security advisories page](https://github.com/fakebane/tricord-public/security/advisories). This lets maintainers coordinate a fix without public disclosure.

Include the affected version or commit, reproduction steps, expected and observed results, impact, and a proposed fix if available. Avoid sharing real credentials or private user data.

## Supported versions

There are no formally supported stable releases yet. Security fixes are currently developed against `main`.
